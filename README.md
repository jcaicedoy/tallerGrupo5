# Taller Grupo 5

Proyecto grupal para implementar una agenda telefónica aplicando pruebas
unitarias, cobertura de código e integración continua con GitHub Actions.

## Funcionalidades

- Registro de contactos.
- Validación de nombres.
- Validación de números telefónicos de 10 dígitos.
- Búsqueda de contactos.
- Pruebas unitarias con pytest.
- Cobertura mediante Coverage.py.
- Integración continua con GitHub Actions.

## Ramas

- `main`: versión estable.
- `developer`: integración de funcionalidades.
- `staging`: código validado y listo para desplegar.
